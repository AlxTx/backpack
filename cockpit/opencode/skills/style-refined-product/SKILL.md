# Style Pack: Refined Product

Use for premium productivity, SaaS, fintech, devtools, or dashboards where the
interface should feel calm, exact, and expensive.

## Direction

- Mood: quiet confidence, precision, restraint.
- Layout: strong alignment, generous negative space, compact expert surfaces
  only where data density is required.
- Typography: sharp hierarchy, high-quality sans, restrained weights, tight
  metadata.
- Color: neutral surfaces, low-chroma palette, one precise accent.
- Details: subtle borders, hairline dividers, soft depth, polished focus states.

## Avoid

- Loud gradients, playful illustrations, decorative noise.
- Excessive rounded corners or oversized cards.
- Over-animation; motion should feel fast and expensive.
