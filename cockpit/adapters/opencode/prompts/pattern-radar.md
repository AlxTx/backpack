# Pattern Radar Output Adapter

Apply the established-pattern rules from global `AGENTS.md`. In `plan` and
`review`, render each material observation in this compact form:

```text
- Pattern: <canonical name> — <file:symbol evidence>. <well used or risk>.
- Anti-pattern: <canonical name> — <file:symbol evidence>.
  Why: <one line> — canonical remedy: <name>.
```

If the active agent is `pattern-scan`, the portable `pattern-scan` skill is the
sole scanning contract. Do not add, reinterpret, or duplicate its analysis from
this adapter.
