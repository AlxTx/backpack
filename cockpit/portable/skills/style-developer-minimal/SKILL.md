# Style Pack: Developer Minimal

Use for developer tools, API products, CLIs, docs, deployment surfaces, and
technical workflows where credibility comes from clarity and speed.

## Direction

- Mood: technical, clean, keyboard-first, fast.
- Layout: strong code/content split, compact navigation, clear command surfaces.
- Typography: crisp sans plus purposeful monospace for technical details.
- Color: monochrome or dark-first base with one technical accent.
- Details: code blocks, command palettes, terminal motifs, precise hover/focus.

## Avoid

- Marketing fluff inside task surfaces.
- Heavy skeuomorphic terminal decoration.
- Low-contrast dark UI that harms readability.
