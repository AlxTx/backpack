# Style Pack: Bento Dashboard

Use for dashboards, admin tools, analytics, AI workspaces, and control surfaces
where multiple signals must be scannable without becoming boring.

## Direction

- Mood: organized, modular, high-signal.
- Layout: responsive bento grid, clear card hierarchy, strong section grouping.
- Typography: compact labels, strong metric typography, readable annotations.
- Color: semantic status colors restrained by neutral surfaces.
- Details: sparklines, badges, compact toolbars, hover affordances, skeletons.

## Avoid

- Equal-size cards with equal visual weight.
- Random metrics without user decisions attached.
- Dense tables before summary and action are clear.
