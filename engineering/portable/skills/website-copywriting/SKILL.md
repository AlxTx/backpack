# Website Copywriting

Use this skill to draft practical, design-ready website copy after the audience,
message, and page/section structure are clear.

## Core principle

Website copy should help visitors understand quickly, feel reassured, and know
what to do next. Clear beats clever. Specific beats generic. Honest beats hype.

## Required inputs

Before writing, identify or infer with explicit assumptions:

1. Page purpose and primary action.
2. Audience and readiness level.
3. Core promise and supporting messages.
4. Objections or hesitations to answer.
5. Tone constraints and forbidden claims.
6. Existing validated wording that should be preserved.

## Writing rules

- Use short headings that can survive real responsive layouts.
- Keep paragraphs scannable: usually 1-3 sentences.
- Prefer verbs that describe what the visitor gets or can do.
- Avoid vague marketing words: innovative, unique, seamless, optimize,
  revolutionize, world-class, next-generation.
- Do not invent metrics, dates, partner names, testimonials, awards, or legal
  claims.
- Explain unfamiliar concepts in simple language before using specialist terms.
- CTA copy should state the next step or what the visitor receives.

## CTA guidance

- Use soft CTAs when commitment is early: "Recevoir les infos", "Être contacté",
  "Découvrir", "Parler au club", "Demander les prochaines dates".
- Use hard CTAs only when the user explicitly wants direct conversion:
  "S'inscrire", "Réserver", "Acheter".
- Avoid generic CTAs unless space is extremely constrained: "Envoyer", "Submit",
  "Cliquez ici", "En savoir plus".

## Output expectation

Write copy in a structure that design and implementation work can use:

```txt
Copy draft:
- Page: ...
- SEO title: ...
- Meta description: ...
- Hero:
  - Eyebrow: ...
  - H1: ...
  - Body: ...
  - Primary CTA: ...
  - Secondary CTA: ...
- Sections:
  1. Section title
     - Heading: ...
     - Body: ...
     - CTA/microcopy: ...
```

Include 2-3 alternatives only for high-leverage elements such as H1 or primary
CTA. Do not create variants for every line unless asked.

## Quality check

- Would a first-time visitor understand the offer in 5 seconds?
- Does every section add a new reason to keep reading or act?
- Are claims factual and supportable?
- Is the primary CTA visible, low-friction, and consistent?
- Does the tone match the brand context rather than generic SaaS copy?
